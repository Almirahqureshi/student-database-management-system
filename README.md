# MySQL Data Analysis Project

## Project Overview

This project demonstrates the design, management, and analysis of a relational database using MySQL.

The project involves creating and working with multiple related tables, inserting data, and using SQL queries to extract meaningful information and identify patterns within the dataset.

## Objectives

- Design and manage a relational database
- Store and organize structured data
- Use SQL to retrieve and analyze information
- Apply filtering, sorting, grouping, and aggregation
- Use JOINs to analyze data across multiple tables
- Generate meaningful insights from the database

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## Key SQL Concepts Used

- CREATE TABLE
- INSERT
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOINs
- Subqueries
- Data Analysis

## Analysis

The project uses SQL queries to analyze the data and answer business-related questions. The analysis focuses on identifying trends, comparing records, summarizing information, and extracting useful insights from the database.

## Project Files

- `student_database_management_system.sql` — Contains the database structure, data, and SQL queries used for the project.

## Skills Demonstrated

This project demonstrates practical skills in database management, SQL querying, relational database design, and data analysis.
